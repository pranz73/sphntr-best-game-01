**Emberlight** — an original 2D canvas arcade survival game. You are a small ember sprite carrying the last lantern flame of a sleeping garden. The flame burns down constantly; gather drifting golden light motes to feed it and score, chain them into combos, and dash (Space or click) to escape the shadow wisps whose touch tears the flame apart. Survive as long as you can — when the flame dies, the run ends. Plain static files, no dependencies, no network: it plays offline in a desktop browser with keyboard and mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
